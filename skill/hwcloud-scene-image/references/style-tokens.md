### 配色纪律

- 色相锁死 **200°–250°**。不允许绿、橙、黄、粉混入（告警色是唯一例外）。
- 饱和度只投放约 **20% 面积**：渐变瓦片、选中描边、按钮。其余是高明度低饱和的蓝白。
- **每个节点里最多 1 个蓝色元素**。禁止多彩图标、禁止每个卡片一种颜色。
- 告警色面积 ≤ 0.5%。

## 3. 投影（三级层高，色永远是深蓝，不是黑）

| 级 | 用途 | 值 |
|---|---|---|
| 1 | 小控件、骨架块 | `0 4 12 rgba(31,71,141,.045)` |
| 2 | 内容卡、节点组 | `0 8 24 rgba(31,71,141,.05)` |
| 3 | 外壳白卡 | `0 22 60 rgba(31,71,141,.085), 0 4 14 rgba(31,71,141,.04)` |
| 4 | 浮标（最重） | `0 18 44 rgba(31,71,141,.15), 0 3 8 rgba(31,71,141,.05)` |
| 特 | 渐变瓦片 | `0 16 34 rgba(74,157,252,.40), 0 0 34 6 rgba(124,107,245,.16)` |
| 特 | 选中节点光晕 | `0 0 0 10px rgba(74,157,252,.10)` |

**不要**用黑色阴影（会显脏）、不要用方向性光源、不要高光、不要 AO、不要体积光、不要玻璃/金属/纹理。全部哑光平涂。

| 层级 | 字号 | 字重 | 颜色 |

| 浮标 | 26px | 500 | `#191919` |

| 标签页（选中） | 22px | 500 | `#191919` |

| 气泡文字 | 21px | 400 | `#191919` |

英文与技术名词（`API`、`MCP`、`Python`、`Namespace`）同字号无衬线混排，**不换字体、不加粗**。除渐变胶囊外，所有文字都是黑或灰。

## 5. 图标

- 统一**蓝色单色线性**，`stroke-width 1.7–1.9`，`stroke-linecap:round`，`stroke-linejoin:round`，不填充。
- 尺寸：渐变瓦片内 `58×58`；浮标 `34×34`；节点内 `22×22`；输入条 `26×26`。
- 风格统一：无彩色、无渐变、无实心块、无阴影。
- 常用语义：节点/拓扑、分层、数据库、文档、闪电（异步）、齿轮、云、盾牌、代码。

## 6. 尺寸护栏（缩略后仍可读的下限）

| 元素 | 下限 |
|---|---|

| 浮标 | 284×94 |

| 连线线宽 | 2px |
