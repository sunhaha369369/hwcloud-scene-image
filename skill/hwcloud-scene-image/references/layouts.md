# 三种版式骨架

版式只解决一个问题：**信息按什么动线走**。动线只有两种合法方向——**水平向右**，或**从中心向下分叉**。禁止斜向长距离穿越，禁止绕圈。

---

## B · 左→右流程（`template-b-flow.html`）

**适用**：输入→生成→产出、转换、整理、构建、流水线、多路输出。
典型标题：「文档配图生成」「数据清洗流水线」「多模型对比评测」。

```
┌─────────────────────────────────────────────────────┐
│ 短标题                                              │
│ ┌──────────────┐                    ┌──────────────┐│
│ │ ▢ 输入例句…  │ ──▶ ◈ 渐变瓦片 ──┬─ │ 微缩卡 1     ││
│ └──────────────┘      (主干)      │  └──────────────┘│
│                          │        └─ │ 微缩卡 2     ││
│                          ▼           └──────────────┘│
│                    ═══ 横向总线 ═══   │ 微缩卡 3     │└─▶ 浮标
│                          │           └──────────────┘│  「一键插入文档」
│                          └────────── │ 微缩卡 4     ││
│                                      └──────────────┘│
└─────────────────────────────────────────────────────┘
```

**配方**

| 零件 | 参数 |
|---|---|
| 输入胶囊 | `448×104 / r52`，左侧 38×38 淡蓝图标块 + 28px 真实例句 |
| 渐变瓦片 | `104×104 / r26`，位于输入胶囊右侧 200px 处，作为"处理器" |
| 总线分叉 | 从瓦片下缘垂 1 条竖线 → 横向总线 → 分 4 条竖线落到卡片 |
| 微缩卡 | `250×356 / r22`，四个横排，间距 24px，左起 210/484/758/1032 |
| 卡内 | 顶部一张微缩图（内联 SVG，`250×268`）+ 下方 `31px/500` 名称，flex 垂直居中，`padding:4px 0 30px` |
| 浮标 | `320×104`，越过内容卡右缘 |

**微缩卡的画法**：每张卡只画该图表类型的**骨架特征**，不追求完整。时序图=4 条虚线生命线+消息箭头；ER 图=2 个带表头的实体+1 个菱形关系；状态机=起始点+3 个状态+1 条回退环；拓扑图=三层树。**每张卡只允许 1 个 `#4A9DFC` 元素做焦点**，其余全是 `#BFD6F1`。

## C-1 · 界面隐喻 · 画布编辑态（`template-c-ui.html`）

**适用**：既讲"一句话生成"，又讲"生成后还能改"。有 AI 输入 + 可编辑画布的组合。
典型标题：「智能图表绘制」「低代码搭建」「对话式建模」。

```
┌─────────────────────────────────────────────────────────┐
│ 短标题                                                  │
│ ┌────────┐ ┌──────────────────────────────────┐         │
│ │ ◈ 瓦片 │ │  ⌗  画一张订单支付的架构图…    ▲ │         │
│ │ 132px  │ └──────────────────────────────────┘         │
│ └────────┘                                              │
│ ┌─────────────────────────────────────────────┐  ┌────┐ │
│ │ 架构图  流程图  结构图                        │  │浮标│ │
│ │ ────                                        │  └────┘ │
│ │  接入层   [节点]  [节点]                     │         │
│ │  服务层   [节点]  [节点✓]──⌐ 改指令气泡       │         │
│ │  数据层   [节点]  [节点]                     │         │
│ │                            [− 100% +]        │         │
│ └─────────────────────────────────────────────┘         │
└─────────────────────────────────────────────────────────┘
```

**配方**

| 零件 | 参数 |
|---|---|
| 渐变瓦片 | `132×132 / r34`，`left 224 / top 272` |
| 输入条 | `972×92 / r26`，`left 372 / top 290`（与瓦片间隙 16px），右端 1344 对齐画布右端 |
| 发送按钮 | `56×56` 圆形 `#4A9DFC`，距输入条右 18 |
| 画布卡 | `1120×414 / r32`，`left 224 / top 426`，底色 `#F8FBFF` |
| 标签页 | `22px`，`left 34/127/220`，选中项下加 `68×3` 蓝线 |
| 图层 | 2 列 × 3 行节点，`268×88`，`left 138/474`，`top 64/182/300` |
| 选中节点 | 右列中排，蓝边+光晕+四角手柄 |
| 指令气泡 | `300×88`，位于选中节点右上，用圆点+40px 虚线相连 |
| 缩放控件 | `168×42`，画布右下，填住空白 |

**注意**：画布卡宽 **1120**（不是 1310），右侧 146px 留给浮标，否则浮标会压住画布内容。

## C-2 · 界面隐喻 · 分层架构选中态（`template-c-arch.html`）

**适用**：强调"只改一块、其余不动"的增量演进叙事。
典型标题：「架构局部迭代」「配置热更新」「灰度发布」。

```
┌──────────────────────────────────────────────┐
│ 短标题                                        │
│ ┌──────────────────────────────────┐  ┌────┐ │
│ │  接入层   [白块]  [白块]          │  │浮标│ │
│ │            │        │            │  └────┘ │
│ │  服务层   [白块]  ▣[选中块]◈      │         │
│ │            └────┬───┘            │  ┌────┐ │
│ │  数据层        [白块]             │  │浮标│ │
│ └──────────────────────────────────┘  └────┘ │
└──────────────────────────────────────────────┘
```

**配方**：上下两层严格垂直对齐（2-2-1），**只在中层→下层汇一次**。上排放 3 块会让汇聚总线横穿全宽，看起来像分割线。

- 目标块：`border 2.5px #4A9DFC` + `0 0 0 10px rgba(74,157,252,.12)` + 四角手柄 + 内部 **86px 渐变瓦片**（放大主体，否则整块不突出）。
- 其余块：白底 + `1px #DCE8F6` + 淡蓝线框图标 + 骨架条，要"退后"但不能糊。
- 两个浮标分别在内容区右上、右中，纵向间距 ≥110px。

## A · 中心辐射（无模板，用 `_blank-shell.html` 搭）

**适用**：能力辐射、多路输出、生态、订阅分发、一个中心多个下游。

```
        ┌──────┐
     ┌──│ chip │
     │  └──────┘
┌────┴───┐
│ ◈ 中心 │   ┌──────┐
│  瓦片  │───│ chip │
└────┬───┘   └──────┘
     │  ┌──────┐
     └──│ chip │
        └──────┘
```

- 中心瓦片 `132×132`，居中偏上；3–4 个 chip 沿**向下**方向辐射，间距 ≥120px。
- 连线：从瓦片下缘出发，先竖直向下 40px，再水平分叉，再落到 chip 上缘。**只允许这种直角折线**。
- 想表现"辐射/生态"时叠 2–3 圈极淡同心虚线圆（`#C9DFFE`，`dasharray 5 6`），透明度 30%。

---

## 怎么选（快速判断）

1. 标题里同时有「生成」和「可修改」→ **C-1**
2. 标题讲「只动一处、其余不变」→ **C-2**
3. 标题是「A 变成 B」「多路产出」→ **B**
4. 标题是「一个中心服务 N 个场景」→ **A**
5. 拿不准 → 选 **C-1**。界面隐喻最容易读懂，也最不容易画歪。
