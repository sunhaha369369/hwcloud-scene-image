# 产品场景图生成器

给一个「标题」，产出一张 1760×1120 的场景图。风格已定型，不要重新设计，只需要**选版式 + 填内容**。

**为什么用 HTML/CSS 渲染而不是 AI 生图**：这套图有大量精确文字（模块名、浮标文案）与 1px 描边。扩散模型会把文字画糊、把描边画抖，无法做到"可复现"。用 HTML 渲染再截图，文字永远清晰、随时可改、可批量。

## 何时使用

- 为某个产品能力写一页 PPT / 官网模块，需要一张"这东西怎么用"的图；
- 一批功能点需要统一风格的配图（10 张、20 张），希望风格完全一致；
- 已有文字稿，需要把"输入→处理→输出"讲清楚；
- 需要中文标签清晰可读的技术示意图（AI 生图做不到）。

**不适用**：需要照片级真实感、需要人物情绪、需要品牌插画风格、需要复杂 3D 视觉。这些直接找设计师或生图模型。

## 铁律（违反任意一条，出来就不像）

1. 画布 **1760×1120**（11:7）、**纯白底**，无渐变无暗角无边框。
2. **三层嵌套卡片**必须存在，坐标**写死不要改**（见下）。这是全系统唯一的"深度"来源。
3. 全图**有且仅有 1 个**渐变图标瓦片（104–132px 见方），它是视觉主体。
4. 色相锁死 **200°–250°**（蓝紫同族视为一色）。唯一暖色 `#F58A8A` 只能用于"告警"。
5. **无人物、无透视、无 3D、无等距、无照片、无环境背景**。所有矩形严格轴对齐。
6. **一图一件事**，信息密度中低。塞不下就分两张。
7. 只输出 **1760×1120** 一个尺寸，**不要**再导出 660×420 之类的缩略衍生图。
8. 所有文字必须是**真实文字**（HTML 文本），不能是图片或路径。

## 固定几何（这个 skill 的核心，照抄）

画布 1760×1120。以下坐标单位为 px，`left/top/width/height`。

| 层 | 元素 | left | top | w | h | r | 说明 |
|---|---|---|---|---|---|---|---|
| L0 | canvas | 0 | 0 | 1760 | 1120 | – | `#FFFFFF` |
| L1 | shell 外壳白卡 | 110 | 66 | 1520 | 968 | 62 | 投影 `0 22 60 rgba(31,71,141,.085), 0 4 14 rgba(31,71,141,.04)` |
| L2 | panel 淡蓝面板 | 140 | 96 | 1460 | 908 | 50 | 渐变见下，描边 `1px #E2EEFD` |
| L3 | content 内容白卡 | 180 | 240 | 1310 | 620–660 | 34 | `#FFF` + `1px #F0F5FB` + `0 10 30 rgba(31,71,141,.05)` |
| L4 | badge 浮标 | 1356 | 自定 | 284 | 94 | 24 | 投影 `0 18 44 rgba(31,71,141,.15), 0 3 8 rgba(31,71,141,.05)` |
| – | title 标题 | 190 | 148 | – | – | – | `60px / 600 / #191919 / ls .5px` |

推导出来的关键边界（改内容时用来对齐）：

- 面板右缘 **1600**、下缘 **1004**；内容卡右缘 **1490**、下缘 **240+h**。
- 内容卡底边到面板底边必须留 **100–140px** 的蓝色带（h 取 620–660）。留得太窄，整张图会像"蓝色只有一个边框"。
- 浮标右缘 **1640**，越过面板 40px、越过外壳 10px —— 这就是"破框"，不要把它塞回卡片里。
- 内容区内部坐标原点 = **(180, 240)**。子元素 `left/top` 都相对画布写绝对值。

面板渐变（**必须止于 #F5FAFF，不能更淡**）：

```css
background:linear-gradient(180deg,#E4F1FF 0%,#E9F4FF 34%,#F2F9FF 74%,#F5FAFF 100%);
```

## 工作流

### Step 1 · 把长标题压成一个短标题

标题通常形如「功能名-一句长描述」或「功能名-使用场景-价值」。规则：

- 取**功能名/场景名**，压到 **4–6 个汉字**：「技术文档与知识库可视化-…」→「文档配图生成」；「架构图/流程图/结构图绘制-…」→「智能图表绘制」。
- 不要照搬长标题，标题位只能放一行 60px。
- 同时提炼 **1–2 个浮标文案**，每个 4–6 字，要是"承诺"或"动作"：「一句话生成」「精准局部修改」「一键插入文档」「布局保持不变」。

### Step 2 · 选版式

| 标题特征 | 版式 | 模板 |
|---|---|---|
| 能力辐射、多路输出、生态、订阅分发 | **A 中心辐射** | `assets/_blank-shell.html` 自行搭 |
| 输入→生成→产出、转换、整理、构建、流水线 | **B 左→右流程** | `assets/template-b-flow.html` |
| 又是"说一句话就出结果"，又是"能局部改/能编辑" | **C 界面隐喻（画布）** | `assets/template-c-ui.html` |
| 存量不动、只改一块、增量演进、保持布局 | **C 界面隐喻（选中态）** | `assets/template-c-arch.html` |

细节见 `references/layouts.md`。

### Step 3 · 改模板

复制一份模板到工作目录，**只改这几处**，壳层 CSS 一行都不要动：

1. `.title` 的文字；
2. 浮标 `.badge` 的文字 + `top`（两个浮标纵向间距 ≥110px，别贴在一起）；
3. 内容区内部的节点/卡片文案、数量、骨架条宽度；
4. 输入条/气泡里的例句换成真实、具体的一句话（如「画一张订单支付的架构图」），**不要写「输入文本」「示例文本」这类占位词**。

删元素时记得同步删掉它的连线与箭头，否则会留下悬空线头。

### Step 4 · 渲染

```bash
python scripts/render.py <input.html> <output.png>
```

脚本会自动把 HTML 复制到 **ASCII 临时目录**再调 Edge/Chrome headless 截图——**中文路径会让 headless 静默失败、输出空白或旧图**，这一步不要自己手写命令绕过。

### Step 5 · 必须看图自检，不许盲发

渲染完用图片查看工具打开 PNG，按 `references/checklist.md` 逐条核对。经验上第一版**一定有 2–4 处要改**，正常要迭代 2–3 轮。

## 文案与骨架条规则

| 项 | 规则 |
|---|---|
| 标题 | 4–6 汉字，名词短语，`60px/600` |
| 浮标 | 4–6 字，动词开头或承诺句，`26px/500` |
| 模块名 | 2–4 字（接入层 / 服务层 / 数据层） |
| 骨架条 | 每节点 **2–3 条**，宽度必须**不等且有节奏**（例如 152/102），等长会像渲染错误 |
| 颜色 | 除渐变瓦片和蓝色按钮外，**所有文字是 `#191919` 或灰**，不用彩色文字 |

## 元素零件（8 个，够用了）

1. **渐变图标瓦片** — `104–132px 见方 / r26–34 / linear-gradient(135deg,#4A9DFC,#5E92F9 45%,#7C6BF5)` + 白色线性图标（`58×58, stroke-width 1.7`）+ 下缘柔光 `0 16 34 rgba(74,157,252,.40), 0 0 34 6 rgba(124,107,245,.16)`。
2. **浮标** — 白底 + 重投影 + 左侧 34px 蓝色线性图标 + 26px 文字，破框放置。
3. **骨架条** — `height:12px / r6 / #BCD3EF`，模拟文本。选中态用 `#A9C7EC`。
4. **虚线连接** — `2px / #BFD6F1 / dasharray 5 5`，箭头是**等腰三角** `M265 170 h14 l-7 12 z`（向下）或 `M456 219 l12 7 l-12 7 z`（向右）。**不能用直角三角形**。
5. **圆角节点** — `268×88 / r20 / #FFF / 1px #C6D9F1`，内部 40×40 淡蓝图标块 + 2 条骨架条。这是 1760 图缩略后仍可见的**下限尺寸**。
6. **选中态** — `border:2.5px #4A9DFC` + `0 0 0 10px rgba(74,157,252,.10)` + 四角 10×10 白底蓝边手柄。**不要画虚线选择框**（会被垂直连线穿过，语义破功）。
7. **指令气泡** — 白卡 + 铅笔图标 + 一句话，与目标节点之间用「圆点锚点 + 40px 虚线」连接，**不要加箭头**（会和手柄打架）。
8. **标签页 / 缩放控件** — `−  100%  +`、`架构图 / 流程图 / 结构图`，用来交代"这是个工具"，也能填补右下角空白。

## 常见错误（都是实际踩过的）

| 现象 | 原因 | 修法 |
|---|---|---|
| 底部出现一条白带，面板像只有边框 | 渐变淡到 `#FBFCFE` | 止于 `#F5FAFF` |
| 蓝色带太窄，整张图发闷 | 内容卡太高 | 内容卡 h 收到 620–660 |
| 缩略后糊成一片灰 | 元素太小太淡 | 节点 ≥268×88；描边加深到 `#C6D9F1`；骨架条 `#BCD3EF`；瓦片 ≥132 |
| 上排 3 块、中排 2 块，中间一条横线像分割线 | 汇聚总线横穿全宽 | 改成上下严格垂直对齐（2-2-1），只汇一次 |
| 图层标签和节点没对齐，一眼别扭 | 手写了 top | `label top = 节点 top + 节点高/2 − 13` |
| 箭头歪、像直角三角形 | 路径写错 | 用等腰三角，见零件 4 |
| 渲染出来是空白/旧图 | HTML 在中文路径下 | 用 `scripts/render.py`，它复制到 ASCII 目录 |
| 浮标压住内容 | 内容卡过宽 | 内容卡宽 1310，右侧 146–270px 留给浮标 |
| 气泡离节点很远、关系读不出来 | 缺锚点 | 圆点 + 40px 虚线 |
